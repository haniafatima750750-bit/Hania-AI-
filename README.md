# Hania AI

Hania AI is a Python desktop chatbot built with Tkinter. It can run in offline mode or connect to Google Gemini through the Gemini API.
This is my first app so tell me if any errors come so i can fix them as soon as possible.
## Requirements

- Python 3.11 or newer
- Internet connection for Gemini chat
- The `openai` Python package for online AI mode

## Run the app

1. Install Python from [python.org](https://www.python.org/downloads/).
2. Open a terminal in the folder containing `app.py`.
3. Install the package for online AI mode:
